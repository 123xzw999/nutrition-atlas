# 营养学全集 · Nutrition Atlas

把身体的细微信号翻译成营养素的语言，再把营养素还原成餐盘上的食物。

一个纯静态的营养学科普站点，零依赖、零构建，双击 `index.html` 即可打开。

## 内容结构

| 页面 | 说明 |
| --- | --- |
| `index.html` | 首页 · 全站目录与速览 |
| `nutrients.html` | **营养素图鉴** · 13 种矿物质 + 10 种维生素，含生理作用、缺乏体征、高危人群、推荐摄入量与食补方向 |
| `symptoms.html` | **身体信号自查** · 35 类常见症状反查可能缺乏的营养素，含关联强度、食补方向与就医红线 |
| `foods.html` | **食补图鉴** · 35 种高营养密度食材，标注关键营养素与实际含量 |
| `male.html` | **男性营养** · 生理差异、六条主线（肌肉 / 前列腺 / 心血管 / 头发 / 精力 / 酒精）、缺口分布、示范餐单 |
| `female.html` | **女性营养** · 五段生命周期（青春期 / 育龄期 / 备孕孕期 / 哺乳期 / 更年期）、缺口分布、示范餐单 |

## 技术说明

- 纯静态：HTML + CSS + 原生 JS，无框架、无构建步骤
- 字体自托管：中文衬线（Noto Serif SC 子集，268 KB）+ 拉丁衬线（Fraunces，67 KB）
- 图片本地化：58 张，统一裁切与色调处理，总计约 4.9 MB
- 响应式：1440 / 1080 / 760 / 460 四档断点

## 设计说明

版式采用「编辑级排印」（Editorial Clinical）：暖纸底色 + hairline 分隔线 + 衬线标题 + 强字号对比，刻意避免模板化的圆角卡片与阴影。

## 免责声明
